## ✨ Overview

**Rule-Based Chatbot v2** is a console-based chatbot written by **Isomiddin**.

This version extends a basic rule-based chatbot by introducing:
- intent detection
- conversational state
- object-oriented design

The project demonstrates how early conversational systems can evolve
into more advanced AI architectures.

## 🚀 Features

### 💬 Intent-Based Responses
- Matches user input to predefined intents
- Supports multiple keywords per intent
- Randomized responses for natural variation

---

### 🧠 Stateful Conversation
- Tracks the last detected intent
- Generates context-aware follow-up responses
- Avoids repetitive fallback replies

---

### 🛡 Robust Fallback Logic
- Gracefully handles unknown input
- Maintains conversation flow
- Prevents program crashes

---

### 🔁 Interactive Chat Loop
- Continuous chat session
- Exit anytime using `exit`
- Clear and friendly terminal interface
